АВТОПОСТИНГ ДЛЯ ТЕЛЕГРАМ-КАНАЛОВ
================================

Бот сам выкладывает посты и викторины в нужное время.
Пост 2 уже стоит в отложке в самом Telegram, его здесь нет.
Квиз (8 октября) и посты 4–7 (9–12 октября) уже лежат в папке
channels/jun_na_starte — вручную их в Telegram НЕ ставь, иначе выйдут дважды.


1. СОЗДАЙ БОТА
--------------
• Открой в Telegram @BotFather и отправь /newbot
• Придумай имя (например «Джун на старте — постинг»)
• Придумай username, он должен заканчиваться на bot (например jun_posting_bot)
• BotFather пришлёт токен — длинную строку вида 123456789:AAH...
  Никому его не показывай: с ним кто угодно может писать от имени бота.


2. СДЕЛАЙ БОТА АДМИНОМ КАНАЛА
-----------------------------
• Канал → нажми на название → «Изм.» → «Администраторы» → «Добавить администратора»
• Найди своего бота по username
• Оставь право «Публикация сообщений» и сохрани


3. ЗАПОЛНИ config.json
----------------------
• Открой config.json в Блокноте или VS Code
• Вместо ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER вставь токен (кавычки оставь)
• В "channels" проверь адрес канала. Если ссылка канала t.me/abc123,
  то пиши "@abc123". Имя слева ("jun_na_starte") — это название папки
  в channels, его не меняй.


4. УСТАНОВИ БИБЛИОТЕКИ (один раз)
---------------------------------
• Открой папку с ботом в Проводнике
• В адресной строке Проводника набери cmd и нажми Enter — откроется консоль в этой папке
• Выполни:
      pip install -r requirements.txt

Если пишет, что python или pip не найден — пробуй  py  вместо python
и  py -m pip  вместо pip.


5. ПРОВЕРЬ
----------
      python bot.py --check     ← проверит все посты на ошибки
      python bot.py --list      ← покажет расписание

Посмотреть, как пост выглядит, не дожидаясь времени:
• создай отдельный тестовый канал с публичной ссылкой, например t.me/nikita_test_123
• добавь туда бота админом
• выполни:
      python bot.py --now channels/jun_na_starte/2026-10-09_23-00.txt --to @nikita_test_123


6. ЗАПУСТИ
----------
      python bot.py

• Не закрывай окно консоли — пока оно открыто, бот работает
• К 23:00 ноутбук должен быть включён и не в спящем режиме
• Если пишет «Нет связи с Telegram» — включи VPN, бот повторит сам
• Если ноутбук был выключен, бот выложит пропущенный пост,
  когда ты его запустишь, но только если опоздание меньше 3 часов
  (это число "max_late_hours" в config.json)


КАК ДОБАВЛЯТЬ НОВЫЕ ПОСТЫ
=========================
Создай файл в папке канала. Имя = дата и время публикации по Владивостоку:

      2026-10-13_23-00.txt         ← обычный пост
      2026-10-14_23-00.quiz.txt    ← викторина

Файлы сохраняй в кодировке UTF-8 (в Блокноте: «Сохранить как» → Кодировка UTF-8).
Бот подхватывает новые файлы сам, перезапускать не нужно.

Разметка в обычном посте:
      **жирный текст**
      `код в строке`
      ||скрытый текст в строке||

      ```java
      код целым блоком (моноширинный шрифт)
      ```

      ```spoiler
      решение, спрятанное под спойлер
      ```

Спойлер и моноширинный шрифт Telegram не даёт совместить,
поэтому решения задач кладём в блок spoiler.

Викторина:
      Текст вопроса
      - неправильный вариант
      + правильный вариант
      - неправильный вариант
      > Пояснение, которое всплывёт после ответа (до 200 символов)


КАК ДОБАВИТЬ ВТОРОЙ КАНАЛ В СЕТКУ
=================================
1. Сделай бота админом нового канала
2. Создай папку channels/novyi_kanal
3. Добавь строку в config.json:
      "channels": {
        "jun_na_starte": "@jun_na_starte",
        "novyi_kanal": "@ssylka_novogo_kanala"
      }

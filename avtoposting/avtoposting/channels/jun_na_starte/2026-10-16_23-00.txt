💼 **Вопрос с собеседования**
Чем String отличается от StringBuilder?

**String**
• неизменяемый: любое «изменение» создаёт новый объект
• его безопасно передавать куда угодно, никто его не испортит
• подходит для текста, который не меняется

**StringBuilder**
• изменяемый: `append()` дописывает в тот же объект
• быстрый, когда строку собирают по кусочкам, например в цикле
• не потокобезопасный (для потоков есть StringBuffer, но он медленнее)

```java
public class Main {
    public static void main(String[] args) {
        String s = "";
        for (int i = 0; i < 1000; i++) {
            s += i; // каждый раз новая строка в памяти
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 1000; i++) {
            sb.append(i); // один и тот же объект
        }

        System.out.println(s.equals(sb.toString())); // true
    }
}
```

**Короткий ответ на собеседовании:** «String неизменяемый, каждое изменение создаёт новый объект. StringBuilder изменяемый, его берут, когда строку много раз дописывают, например в цикле».

🧩 **Задача (Python)**
Найди повторяющиеся числа в списке.
Вход: [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]
Выход: 1, 5, 3

Сделай двумя способами: через обычный список и через множество (set). Решение ниже, сначала попробуй сам 👇

```spoiler
nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]

# Способ 1: через список
seen = []
dups = []
for n in nums:
    if n in seen and n not in dups:
        dups.append(n)
    seen.append(n)
print(dups)  # [1, 5, 3]

# Способ 2: через множество
seen = set()
dups = set()
for n in nums:
    if n in seen:
        dups.add(n)
    seen.add(n)
print(dups)  # {1, 3, 5}
```

💡 Второй способ быстрее. Проверка `in` для множества почти мгновенная, а по списку Python каждый раз перебирает все элементы. На миллионе чисел разница огромная.

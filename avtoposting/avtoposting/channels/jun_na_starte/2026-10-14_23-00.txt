🧩 **Задача: палиндром**
Проверь, читается ли строка одинаково слева направо и справа налево. Регистр и пробелы не учитывай.
Вход: «А роза упала на лапу Азора» → true
Вход: «Привет» → false

Реши на Java или Python. Решения для обоих языков ниже 👇

```spoiler
// Java
public class Main {
    static boolean isPalindrome(String s) {
        String clean = s.replace(" ", "").toLowerCase();
        int left = 0;
        int right = clean.length() - 1;
        while (left < right) {
            if (clean.charAt(left) != clean.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(isPalindrome("А роза упала на лапу Азора")); // true
        System.out.println(isPalindrome("Привет")); // false
    }
}

# Python
def is_palindrome(s):
    clean = s.replace(" ", "").lower()
    return clean == clean[::-1]

print(is_palindrome("А роза упала на лапу Азора"))  # True
print(is_palindrome("Привет"))  # False
```

💡 В Java идём двумя указателями навстречу друг другу. В Python хватает среза `[::-1]`, который переворачивает строку.

🧩 **Задача (Java)**
Переверни строку, не используя метод reverse().
Вход: «привет» → выход: «тевирп»

Решение ниже, сначала попробуй сам 👇

```spoiler
public class Main {
    public static void main(String[] args) {
        String s = "привет";
        StringBuilder sb = new StringBuilder();
        for (int i = s.length() - 1; i >= 0; i--) {
            sb.append(s.charAt(i));
        }
        System.out.println(sb); // тевирп
    }
}
```

💡 StringBuilder быстрее, чем `+=` в цикле: он не создаёт новую строку на каждом шаге.

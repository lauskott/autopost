📌 **Шпаргалка (Python): генераторы списков**

Генератор списка собирает новый список из старого в одну строку.

```python
nums = [1, 2, 3, 4, 5, 6]

# 1. Преобразовать каждый элемент
squares = [n * n for n in nums]
print(squares)  # [1, 4, 9, 16, 25, 36]

# 2. Оставить только нужные
evens = [n for n in nums if n % 2 == 0]
print(evens)  # [2, 4, 6]

# 3. Отфильтровать и преобразовать сразу
words = ["java", "go", "python", "c"]
long_upper = [w.upper() for w in words if len(w) > 2]
print(long_upper)  # ['JAVA', 'PYTHON']
```

Читается почти как фраза: «n в квадрате для каждого n из nums».

⚠️ Если генератор не помещается в строку или в нём два вложенных цикла, напиши обычный for. Короче не значит понятнее.
